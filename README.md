# Android Bluetooth Gamepad — RetroBox

Research and experiments for connecting a Sony DualShock 3 controller to a rooted Android 12 TV box (iMETBOX M3).

**Status:** wired gamepad works; wireless Bluetooth DS3 bonding is not fixed. Experimental process-instrumentation work has passed isolated tests only. **Do not run experimental Bluetooth injectors or replace system libraries.**

See the forthcoming research snapshot PR for the full source archive, test evidence, safety boundaries, and S7-C4C engineering handoff.
